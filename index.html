How It Works

Working process of the Portable ECG Monitoring System.

1. ECG Electrodes

ECG electrodes detect the electrical activity of the heart and send the signal to the ECG sensor.

2. AD8232 ECG Sensor

The AD8232 receives and conditions the ECG signal so that it can be processed by the microcontroller.

3. Arduino UNO

Arduino reads the analog ECG signal and processes the incoming data.

4. Signal Processing

The ECG signal is processed to obtain useful information such as the heart-rate value.

5. OLED Display

The processed information can be displayed on the OLED screen for easy viewing.

About

Portable ECG Monitoring System

Project Overview

PulseCare is an academic prototype designed to demonstrate portable ECG signal monitoring.

The system uses ECG electrodes, an AD8232 ECG sensor, Arduino UNO and an OLED display to demonstrate the acquisition and display of ECG signals.

Prototype Components

  • ECG Electrodes
  • AD8232 ECG Sensor
  • Arduino UNO
  • 0.96-inch OLED Display
  • Portable Power Supply

This website is an educational prototype interface and is not intended for medical diagnosis.
